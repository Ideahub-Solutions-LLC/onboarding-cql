CQL ONBOARDING - SIMPLE DEPLOYMENT

Runtime: Next.js
Storage: SQLite/libSQL
Authentication: email and password
Logout: /api/auth/logout
Cloudflare Access: not used
Resend magic links: not used

LOCAL
1. npm ci
2. Configure .env.local
3. npm run dev
4. Open http://localhost:3000

PRODUCTION VARIABLES
DATABASE_URL
DATABASE_AUTH_TOKEN (only for hosted libSQL)
AUTH_SECRET
VAULT_KEY
OWNER_EMAILS
ADMIN_PASSWORD

Vercel cannot persist file:.data/cql.sqlite. Use a hosted persistent SQLite/libSQL URL on Vercel, or run the application on a Node server with persistent disk.

ACCEPTANCE
- /api/health returns 200.
- Owner email/password login succeeds.
- Incorrect password fails.
- Sign out clears cql_session and returns to the sign-in page.
- Owner can create a client email/password.
- Client can sign in and access only the assigned application.
